The artefacts

Seven components, and the discipline to stop there.

Each one earns its place by doing a job the plain page cannot. Nothing on this list is decoration, which is why the list is short.

The hero artefact

A terminal showing a true transcript

Use it well

What it does, and what it doesn't.

This is a house style, not a design system. A few things are deliberately out of scope. Call them out so you can plan around them.

In scope

  • Landing pages, docs sites, dashboards, developer tools
  • One fixed palette, validated, in both themes
  • Seven components with markup and CSS
  • An ordered procedure for revamping an existing site
  • Copy rules, with a banned vocabulary

Out of scope

  • A component library. This ships CSS to copy, not a package
  • Client work where the brand hue is contractual
  • Consumer apps, marketing microsites, anything playful
  • Charts and data visualisation beyond a stat band
  • A light-theme atmospheric texture, which has no honest inversion
